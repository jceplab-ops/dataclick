Behavior Recorder

Record behavior by frequency, duration, or interval. Export time-binned CSV.

Assessment type

Leave session length blank to stop manually. If you set it, recording ends automatically.

Each cycle is the interval followed by the record time, so a 10-second interval with 5 seconds to record repeats every 15 seconds. Leave session length blank to stop manually; otherwise only whole cycles are recorded.

Signal at the end of each interval

iPhone Safari cannot vibrate, and the iPhone silent switch mutes the beep, so use screen color there. On Android, vibration and sound both work. Keep the screen on and the app in front while recording.

Buttons

Up to 6 buttons. Marking buttons as Response and Reinforcement adds a column to the event log showing how long after a response each reinforcer occurred.

Up to 6 behaviors. Each gets its own button and its own timing, and they can run at the same time.

Up to 6 behaviors. After each interval you mark every behavior that occurred during it.
